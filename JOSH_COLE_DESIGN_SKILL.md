# Josh Cole Creative website design reference

Use the [Design System page source](src/app/design-system/page.tsx) for the current website rules and examples. The [shared stylesheet](public/portfolio/fonts/site-typography.css) implements the three typography roles and the common control family. The [portfolio renderer](src/portfolio) supplies the Home and Culture shell, content layout and project-specific presentation.

The maintained visual brand guide is in ColeOS. The website reference describes the shipped implementation, not a new branding direction. Keep the two aligned when changing shared rules. Preserve existing project identities, original specimens and approved résumé print and PDF treatments.

The [v0.3 design proposal](docs/design-system-v0.3-archive.md) is historical. Its legacy accent gradient, Syne/Inter hierarchy, square-only controls and doors navigation are not current defaults.
