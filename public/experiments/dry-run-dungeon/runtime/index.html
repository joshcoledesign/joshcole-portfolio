Dry Run Dungeon

An agent dry-runs every move in a small learned world model before it takes it. It plans in the model, never in the engine. Switch the model off to watch the same agent without imagination, stretch the horizon until its predictions dissolve, or drop a teleporter it has never seen. Press a move key to take over.
